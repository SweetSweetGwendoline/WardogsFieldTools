# WARDOGS Field Tools

A lightweight artillery calculator and interactive map for WARDOGS. Set your artillery and target positions to calculate range, bearing, and estimated elevation for the L81 mortar and SPH-2 artillery.

## Features

- Three interactive maps with pan, zoom, and click-to-place positions.
- Weapon range circles, coordinate grid, and tower, spawn, and zone overlays.
- Coordinate-pair pasting, decimal dots or commas, and remembered inputs.
- Shareable solution links and editable map layouts.

Runs as a static page (open `index.html` locally) or host it on GitHub Pages.
Map overlays remain provisional.
